# BikerVoice GPT gateway

Node.js 22+, no dependencies. Keep OPENAI_API_KEY and BIKER_ACCESS_TOKEN in the host secret store or local environment, never in GitHub or the APK. Generate a random token (at least 24 characters), for example with openssl rand -hex 32. Set OPENAI_MODEL if your API project requires a different supported model; default gpt-5. Run node server/server.mjs. Default listener is 127.0.0.1:8080; place a TLS reverse proxy in front (or use a managed HTTPS host and set HOST=0.0.0.0). Configure /chat on the HTTPS host, and enter the full URL and the gateway token in BikerVoice. The OpenAI key stays on the server. The app sends up to 12 recent text messages; Android's recognition service handles microphone speech. A separate OpenAI API account with billing and model access is required. This is not the ChatGPT subscription. Set project budget alerts and host-level rate limits. The included gateway limits requests to 10/min globally and 2 concurrent. Do not expose it without HTTPS. No secrets should be sent in chat. Android speech service and TTS must be available on the device.

Manual smoke test: install APK, open settings, enter gateway URL and token, ask a typed question, then tap microphone and speak Russian. Verify response text, voice, expressions, error handling, and Stop.
